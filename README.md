### 🚀 Featured Projects

**[Smart Attendance Planner](https://github.com/purnasaikarthik)**
Tracks subject-wise attendance and calculates the safest way to bunk without falling below the required percentage. Flutter + Supabase (PostgreSQL, RLS, Auth).

**[24BUS](https://github.com/purnasaikarthik)**
A multi-tenant campus bus booking platform for passengers and admin bus coordinators, with QR-verified registration. Flutter + Supabase.

**[Drain Monitor](https://github.com/purnasaikarthik)**
A bilingual (English/Telugu) community-reporting tool for flagging blocked village drains, with GPS-tagged photo uploads — built for a real rural infrastructure problem.

**[QwikLearn](https://github.com/purnasaikarthik)**
An AI-powered study companion that ingests PDF study material to help students learn faster. Flutter + Riverpod + Supabase.

**[Mystery Detective](https://github.com/purnasaikarthik)**
A procedurally generated deduction game with AI suspects and a custom rule-based solvability engine, built from a 46-part architecture spec.
